행운의 룰렛 - 랜덤 추첨 프로그램
================================

[실행 방법]
1. 이 폴더의 index.html을 더블클릭합니다.
2. 참가자 이름을 한 줄에 한 명씩 입력합니다.
3. 당첨 인원을 설정하고 "행운의 룰렛 시작"을 누릅니다.
4. 다시 추첨하려면 "결과 초기화"를 누릅니다.

별도 프로그램 설치나 인터넷 연결은 필요하지 않습니다.
폭죽 라이브러리도 vendor 폴더에 포함되어 있어 오프라인으로 작동합니다.

[초기 테스트 데이터]
김민준, 이서연, 박지훈, 최하은, 정도윤, 한유진, 오시우, 윤채원, 강현우, 송아린

[자동 테스트]
tests.html을 더블클릭하면 핵심 추첨 로직과 오류 처리 테스트 결과를 볼 수 있습니다.

[오픈소스]
- 이름: canvas-confetti 1.9.4
- 공식 저장소: https://github.com/catdad/canvas-confetti
- 브라우저 배포 파일: 공식 README에서 안내하는 jsDelivr 패키지 파일
- 라이선스: ISC License
- 라이선스 전문: vendor/LICENSE-canvas-confetti.txt

[파일 구성]
- index.html: 실행 화면
- style.css: 보라·파랑 게임형 디자인과 모바일 반응형 스타일
- app.js: 명단 처리, 무작위 추첨, 룰렛, 중복 방지, 결과 초기화
- tests.html: 브라우저 자동 테스트
- vendor/: canvas-confetti 배포 파일 및 라이선스
